# Compare the Psalms

Interactive visualization of psalm-to-psalm similarity, built with Vite +
TypeScript + D3. Reads `public/data/similarity.json`, generated by the
`pipeline/` package — run that first if the file is missing.

Two views over the same data:

- **Similarity Matrix** — a 150x150 canvas heatmap, colored by a sequential
  Turbo color scale, with book-boundary guides, hover tooltips, and
  click-to-select.
- **Network Graph** — a D3 force-directed graph; an adjustable threshold
  slider controls which psalm pairs are drawn as edges, nodes are colored by
  the traditional five-book division of the Psalter.

Selecting a psalm (via the grid, either visualization, or the jump-to-psalm
field) populates the detail panel: incipit, stats, top distinctive lexemes,
and a ranked list of the most similar psalms with the shared vocabulary that
explains each match.

## Development

```bash
npm install
npm run dev      # dev server
npm test         # vitest unit tests (pure logic: ranking, network-graph
                  # construction, color scales, state store, data loading)
npm run lint
npx tsc --noEmit
npm run build     # production build to dist/
```

## Architecture

```
src/
  types.ts              JSON payload shape (mirrors pipeline export)
  lib/                   pure, unit-tested logic
    books.ts              traditional five-book division
    ranking.ts             top-N similar psalms
    network.ts             threshold -> {nodes, edges}
    matrix.ts               matrix statistics
    colorScale.ts           color scales (sequential + categorical)
  state/store.ts         minimal observable store (selected psalm, view, threshold)
  data/loadSimilarityData.ts   fetch + validate the JSON payload
  viz/                   DOM/canvas/SVG rendering (heatmap.ts, network.ts)
  components/            detail panel, psalm picker
  main.ts                wiring
```
