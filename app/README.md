# Compare the Psalms

Interactive visualization of psalm-to-psalm similarity, built with Vite +
TypeScript + D3. Reads `public/data/similarity.json`, generated by the
`pipeline/` package — run that first if the file is missing.

A method dropdown in the header switches between every comparison method the
pipeline exports (currently lexical and verb-morphology similarity); two
views render whichever method is selected:

- **Similarity Matrix** — a 150x150 canvas heatmap, colored by a sequential
  Turbo color scale, with book-boundary guides, hover tooltips, and
  click-to-select.
- **Network Graph** — a D3 force-directed graph; an adjustable threshold
  slider controls which psalm pairs are drawn as edges, nodes are colored by
  the traditional five-book division of the Psalter. The default threshold
  is picked per method (98th percentile of that method's own score
  distribution — see `lib/matrix.ts`'s `percentileOffDiagonal`), since
  different methods have very different baseline similarity.

Selecting a psalm (via the grid, either visualization, or the jump-to-psalm
field) populates the detail panel: incipit, stats, top distinctive terms for
the selected method, and a ranked list of the most similar psalms with the
shared terms that explain each match. Switching methods keeps the selected
psalm and re-renders everything against the new method's data.

## Development

```bash
npm install
npm run dev      # dev server
npm test         # vitest unit tests (pure logic: ranking, network-graph
                  # construction, color scales, state store, data loading)
npm run lint
npx tsc --noEmit
npm run build     # production build to ../compare/ (see vite.config.ts)
```

`app/index.html` is a Vite source entry — it only runs under `npm run dev`
(module imports, `import.meta.env`, etc. are unbundled). It is not servable
as a plain static file. `npm run build` produces the real deployable page at
`../compare/index.html`, which the main site (`../index.html`) links to.

## Architecture

```
src/
  types.ts              JSON payload shape (mirrors pipeline export)
  lib/                   pure, unit-tested logic
    books.ts              traditional five-book division
    ranking.ts             top-N similar psalms
    network.ts             threshold -> {nodes, edges}
    matrix.ts               matrix statistics
    colorScale.ts           color scales (sequential + categorical)
  state/store.ts         minimal observable store (selected psalm, view, threshold)
  data/loadSimilarityData.ts   fetch + validate the JSON payload
  viz/                   DOM/canvas/SVG rendering (heatmap.ts, network.ts)
  components/            detail panel, psalm picker
  main.ts                wiring
```
